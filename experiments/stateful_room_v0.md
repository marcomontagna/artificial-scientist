# Stateful room v0 — preregistered integration experiment

September 26, 2026. Build the next complete observe–predict–act–update loop in a small room whose state persists. Known tabular Bayesian learning and shallow predictive-information planning; no new algorithm, learned policy network, AGI, or general rule discovery claim. Keep previous experiments frozen.

## Interface, support and five worlds
The visible state is s=2*power+door, two binary sensors (four known states). Actions are 0: press power switch; 1: press door control; 2: wait. The learner is given these channels/cardinalities but no transition rules or allowed-action list conditioned on state. Every attempted action consumes one real transition. Observe next state and accepted/blocked flag. Encode outcomes0..3 as accepted next-state IDs and outcome4 as blocked with unchanged visible state. Accepted/no-change and blocked are distinct observations. Blocked implies no visible change is supplied structural support, not discovered. No environmental reward, terminal win or reset action.

Each episode starts at visible state0. State persists for96 actions. Fresh learner per episode. Five fixed development cells:
1. gate_on: power action always toggles power; door action toggles door iff power=1, otherwise blocked; wait accepted/no-change.
2. gate_off: same but door toggles iff power=0.
3. directional: same but door toggles iff power != door (opening and closing require different power settings).
4. random_room: every action is accepted and selects next visible state uniformly0..3, independent of current state.
5. hidden_arm: evaluator-only arm starts0. Power toggles visible power and sets arm1. Door toggles iff arm1 (otherwise blocked); every door attempt clears arm0. Wait is accepted/no-visible-change and clears arm0. Arm is never an observation or learner input. This is a deliberate failure of the learner's four-state Markov assumption.
All four visible states are reachable in each deterministic primary world. The first three are primary; random and hidden-arm controls remain separate regardless of results. World identities/rules are evaluator metadata only. These are five designed cells, not a sample of arbitrary universes.

## Learner and policies
All policies share independent Dirichlet(0.5,0.5,0.5,0.5,0.5) priors over each of the12 (state,action) transition rows. Observing an outcome increments that row/category only. Learn transition and blocked probabilities without a library of door-rule hypotheses. State representation, transition-table form, stationarity assumption and prior remain supplied. No latent-state inference or rule invention.
For row c, p=c/sum(c), define g(c)=[H(p)-sum_o p_o H((c+e_o)/(sum(c)+1))]/12. This is information about an independent future transition outcome in a uniform12-row query distribution, not parameter information gain or raw surprise. Compute entropy with zero-safe logs, reject scores below -1e-10 before clamping tiny negative roundoff. Four policies in this order:
- random: uniform actions0..2.
- cycle: actions0,1,2 repeating, starts0.
- greedy: choose action maximising g(row(s,a)).
- lookahead2 (primary): choose action maximising g(row(s,a)) + sum_o p(o|s,a) max_b g(row_D+(s'(o),b)), where D+ contains the hypothetical first observation, s'=o for accepted outcomes and s'=s if blocked. Score prospective knowledge at the reachable next state, not an oracle world. Replan after each real observation; no commitment to a second action. Tie within1e-12 uses independent policy RNG. Imaginary updates never mutate the live model. This optimises the sum of two predictive-information rewards, a shallow belief-space planning surrogate, not a guarantee of globally optimal query-risk reduction.

## Evaluation, queries and fixed decision
At initialization and after each real transition compute evaluator-only exact expected one-step log loss averaged uniformly over all12 state/action queries, subtract the true query entropy for excess loss. Also compute mean squared probability error (sum over five categories, then average rows), blocked-probability squared error, and visited-row coverage. Query outcomes are not sampled, never updated into the learner, and cannot reset its physical state. For hidden_arm, define reference one-step rows by averaging arm0/1 equally at each visible state; this is a chosen evaluator reference, not the agent's on-policy hidden-state conditional distribution.
At fixed checkpoints0,24,48,96 also report exact expected joint two-step outcome log loss for uniform4 starting visible states ×9 fixed OPEN-LOOP action pairs, and excess over true joint entropy. Learner prediction of outcome pair(o1,o2) is p_D(o1|s,a1) p_D+o1(o2|s'(o1),a2), including a hypothetical Dirichlet update when the row repeats. Each query pair starts from an unchanged copy of the current learned model. Truth propagates its own state. For hidden_arm, marginalise an initial fair arm through both steps; never reset arm between steps. All evaluator query errors are predictions of independent experiments, not calibration claims.
Primary endpoint is mean post-update one-step excess log loss over steps1..96 (arithmetic mean, nats per row per step), averaged equally over the three deterministic worlds within each seed. In deterministic worlds g for counts n in one outcome category depends only on n, so greedy reduces to local least-visited action selection and lookahead2 is a shallow count-based exploration planner. Do not interpret a benefit as evidence that information-theoretic acquisition is superior to visit counting. Compute paired lookahead2 minus each random/greedy difference (cycle is a descriptive sanity arm, outside the screen); report32-seed mean, sample SE and descriptive normal95% interval with z=1.959963984540054. Practical screen passes only if both pooled means <= -0.01 AND all six per-world mean differences (three primary worlds × random/greedy) <= +0.01. Report paired per-world means, SEs and normal95% intervals too. If the pooled criterion passes but a per-world guard fails, label the result mixed and screen failed. Cycle comparisons remain descriptive only. Completeness requires exactly640 episodes. Controls and two-step secondary metrics cannot rescue a failed primary screen. Pass supports only shallow model-based coverage planning benefit in these designed cells; fail means no claimed planning advantage and no post-result tuning. Report one-step final and two-step checkpoint outcomes for all cells even if worse; no pooled-independent-world fiction or held-out claim. Knowledge objective does not reward opening the door.

## Prior-art boundary
[Prediction-Oriented Bayesian Active Learning](https://proceedings.mlr.press/v206/bickfordsmith23a.html) establishes predictive-information acquisition. [Efficient Bayes-Adaptive Reinforcement Learning using Sample-Based Search](https://arxiv.org/abs/1205.3109) (Guez, Silver, Dayan2012; primary abstract checked for this protocol) establishes substantial prior art for planning with uncertain learned dynamics. We implement neither BAMCP nor a novel RL method: this is a tiny exact depth-two integration baseline, with understanding measured through limited predictive proxies. No claim that RL requires a neural network. Full chess, learned representations, changing laws and autonomous scientific explanations remain beyond this experiment.

## Pre-run critique and fixed interpretation
Claude's protocol-only review is preserved in research/claude_stateful_room_review.md. Starting at0, cycle0/1/2 in gate_on follows0→2→3→3→1→1→1→3→2→2→0→0→0; gate_off likewise visits all12 state/action rows once in12 steps. In directional it follows0→2→3→3→1→0→0, visiting only6 rows forever. Thus cycle is an informative sanity comparison, excluded from the primary screen before any study sampling. With fixed symmetric priors and deterministic row outcomes, balanced visits are a strong coverage baseline; do not credit an information principle for a count-based effect. The practical0.01 margin is chosen for this toy, not derived from a theorem or powered confirmatory design. For scale, a wholly unvisited deterministic row initially contributes ln(5)/12≈0.134 nats to uniform-row loss.

The per-world guard prevents a pooled benefit from concealing a mean harm larger than0.01 in any primary cell. All controls, per-world losses and intervals remain visible. No oracle planner, new parameter-information baseline or extra on-policy hidden-arm-reference metric is added in this bounded version. The hidden-arm reference is artificial and stated explicitly; the learner is not equipped to solve this aliasing. Primary intervals reflect only action/tie randomisation in fixed deterministic worlds.
