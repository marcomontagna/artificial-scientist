# Interactive switch laboratory v0 — preregistered integration prototype

September 25, 2026. Understanding-first active learning in a resettable simulated laboratory, not a new RL algorithm, autonomous concept discovery, or chess. Known Bayesian predictive-information acquisition is integrated with a small world model; no policy network or environmental reward. Previous diagnostic studies are complete and unchanged.

## Interface and worlds
Three binary switches A/B/C create eight configurations indexed 0..7 in binary order, A as most significant bit and C as least significant. One action sets all three switches and observes a binary lamp; action8 observes a separate fair noise lamp. Each trial resets, so no temporal dynamics or delayed planning. The learner knows the action interface and candidate library, not the true rule/world label. The noise lamp's irreducibility is supplied in every candidate, not discovered.
Six fixed development world cells: A with flip noise0.05; A AND B with0.05; A XOR B with0.05; A OR C with0.20; completely random lamp0.5; majority(A,B,C) with0.05 (outside the structured library). All stationary. Each world uses 40 new development seeds400..439, 48 experiments per policy. Noise uniforms keyed independently by seed, step, action, with the same table shared across policies; policy randomness independent. Observation RNG seed=5000003+seed, precomputed48x9 uniforms; policy RNG seed=6000011+100*seed+policy_index, shared across world cells (no world key). Policy order is hybrid_epig, hybrid_random, hybrid_roundrobin, structured_epig. Smoke uses seed390 only (already inspected in the causal study; reused for resources, not a new holdout); tests use synthetic fixtures7/11. No held-out generalization claim. Reserved rule families and sequence seeds1000..1049 remain untouched.

## Learners and actions
Structured hypotheses: 17 Boolean functions (two constants, six literals A/B/C and negations, three pairwise AND, three OR, three XOR), each with noise0.05 or0.20, plus a fair lamp:35 distinct predictive tables. Noise action8 always0.5. Equal structured weights. Hybrid learner initially assigns0.8 total mass to structured hypotheses and0.2 to an independent Beta(1,1) table for each of the eight switch settings. Bayesian updates use normalized pre-outcome likelihoods; the flexible model's posterior weight and Beta counts update from the selected action only. The noise action updates neither beliefs nor counts. This is a supplied flexible fallback and reweighting, not invention of rules.
Four policies: hybrid predictive-information acquisition (primary); identical hybrid with uniform random switch actions0..7; identical hybrid round-robin0..7 starting at0; structured-only predictive-information acquisition (ablation). All48 observations, no oracle labels/resets. Baselines exclude the known-irrelevant noise lamp, avoiding a trivial advantage from skipping a supplied distractor. Primary acquisition still scores all nine actions. Record acquisition/prediction/update compute time separately for each policy; equal observations do not imply equal compute. Primary acquisition maximizes expected reduction in mean predictive entropy of an independent future lamp observation across the uniform eight switch configurations: Hmean(current query predictions) - sum_y p(y|a,D) Hmean(predictions after hypothetical(a,y)). Exact enumeration of y and finite library, conjugate Beta fallback. This is predictive information, not raw outcome surprise. Fair noise action scores zero. Use stable entropy terms (log/log1p), clamp roundoff-negative acquisition scores to0, and maintain model weights in log-space. Choose only among switch actions0..7 (including when all scores are <=1e-12); still display action8 score exactly0. Break scores within1e-12 of maximum uniformly using independent policy RNG. Record noise-action counts per cell/policy, expected zero by this supplied action filter. Hypothetical updates must never mutate live state.

## Evaluation and falsifier
Before any experiment, and after each update, evaluator computes exact expected Bernoulli log loss over the uniform eight query settings using the hidden true probabilities. Queries are analytical evaluations only: no query outcomes reach the learner, and no query data updates it. Also report excess log loss over true entropy and mean squared probability error (excess Brier), which are predictive accuracy measures, not proof of calibration. Record actual chosen-action pre-update probability, action scores, observation, all8 query probabilities, posterior top hypotheses, fallback weight, and query scores at each step. Evaluator truth is separate and labeled in replay.
Primary endpoint: mean per-seed normalized area under excess-query-log-loss curve: arithmetic mean over post-update steps1..48, in nats per query-cell per step, averaging equally across the four in-family nonrandom world cells. Paired differences primary minus random and primary minus roundrobin; report mean, sample SE and descriptive normal95% intervals over40 seed aggregates. Exploratory practical screen: mean difference <= -0.01 nats for BOTH comparators; confidence intervals reported, not treated as confirmatory. Fixed final-step48 score secondary; retain every world/control even if worse. Majority stress and fair noise are separate, not included in primary aggregate. Compare majority hybrid vs structured-only to expose benefit/cost of supplied fallback; no guaranteed win. Primary worlds exactly match supplied hypothesis/noise tables; acquisition targets the same query distribution used for evaluation, unlike random/roundrobin. This is a favorable, well-specified toy. The Boolean library is not symmetric under complement (no NAND/NOR/XNOR). Also record evaluator-only posterior mass on the matching true structured hypothesis (null for majority), labeling this supplied-library identification, not rule invention. All cells share seeds; never pool them as independent trials. No tuning after outcomes. Pass licenses only an exploratory predictive sample-efficiency benefit in the four supplied-library worlds. Fail means no claimed primary benefit and no post-result acquisition tuning. Stress/noise cells cannot rescue a failed primary screen; show all four policies on both controls.

## Prior-art boundary
[Prediction-Oriented Bayesian Active Learning](https://proceedings.mlr.press/v206/bickfordsmith23a.html) (Bickford Smith et al., AISTATS2023) already introduces EPIG for predictive information under a target-input distribution. [VIME](https://arxiv.org/abs/1605.09674) uses information gain about dynamics as an exploration bonus inside RL. [DreamerV3](https://arxiv.org/abs/2301.04104) learns world models and improves task behavior through imagined scenarios. Primary abstracts checked September25,2026. This exact finite laboratory is an illustrative integration of established ideas; these sources do not confer novelty, universal scientific ability or calibration on our prototype.
